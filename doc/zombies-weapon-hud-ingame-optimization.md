# 僵尸模式武器卡片：实机效果优化方案

日期：2026-09-23。状态：本轮代码调整已实施，待实机视觉验收；具体取值与验证记录见第 8 节。

依据：用户提供的实机截图 `1fd8001a7675c349b01abdc8d3b9e2aa.png`，以及“枪械图片以本身图片右侧为基准对齐，不同分辨率但相同比例的图片应正确适配”的补充要求。

本方案接续 [SVG 分析与第一轮实现记录](zombies-weapon-hud-svg-analysis.md)。原稿保留在 [zom-original.svg](zom-original.svg)，第一轮优化稿为 [zom.svg](zom.svg)。本轮根据实机反馈修正排版，不要求逐像素复刻 SVG；与旧方案冲突时，以本文为后续优化方向。

## 1. 目标与约束

实机截图中，枪图比较突出，枪口接近左侧竖条；弹药数字显得细弱，模式图标与备弹之间略显分散。先改善内部留白和信息主次，不继续放大卡片外框。

- 维持紧凑尺寸和右下角锚点，卡片比例仅在显示适配需要时微调。
- 暂不更换字体，不引入新的数字字形或字体资源。
- 弹匣与备弹按约 `8:3` 的可见高度关系联动调整。
- 保留实时弹药、低弹量提示、升级等级和射击模式的数据来源。
- 稀有度颜色继续使用项目映射：普通 `#22C55E`、稀有 `#3B82F6`、史诗 `#A855F7`、传奇 `#FF9800`。
- 截图是局部裁图，不能由此认定整屏占比过大或过小。外框大小最终需要完整游戏画面验收。

## 2. 枪图：以完整图片右侧为基准

### 固定右锚点

在弹药区左侧保留一个稳定的武器图片区域。枪图的完整图片框右边缘对齐该区域的右锚点，不能按枪械可见轮廓、图片中心或左边缘定位。

```text
imageRight = 固定的武器图片区域右边缘
imageLeft  = imageRight - displayWidth
imageTop   = imageCenterY - displayHeight / 2
```

这里的 `imageRight` 是卡片布局锚点，不取当前弹药字符串的左边缘；弹药位数改变时，枪图不能跟着移动。

保留素材自带的透明边缘，不自动裁剪透明像素。不同素材的枪械可见轮廓可能因此有少许偏移，这是图片自身的构图差异，不应擅自用可见枪托或枪口重新对齐。

### 相同比例、不同分辨率

显示大小由 HUD 区域决定，不能直接跟随原图像素数。以下素材应占据相同大小的显示框：

| 原图尺寸 | 宽高比 | 显示规则 |
| --- | --- | --- |
| `384×128` | `3:1` | 等比适配，右对齐 |
| `768×256` | `3:1` | 与上一行显示尺寸一致 |
| `1536×512` | `3:1` | 与上一行显示尺寸一致 |

通用计算方式：

```text
fit = min(regionWidth / sourceWidth, regionHeight / sourceHeight)
displayWidth  = sourceWidth  × fit × imageScale
displayHeight = sourceHeight × fit × imageScale

imageLeft = imageRight - displayWidth
```

对于比例已知且相同的素材，也可以直接由比例计算目标框并采样完整纹理，不必每帧查询原图尺寸。若需读取尺寸，应随资源加载缓存，并在资源重载后更新。

需要核对的是完整纹理是否正确映射到目标框。优先使用完整归一化 UV `(0,0)–(1,1)`，或使用源区域和纹理尺寸相匹配的绘制参数，避免只取高分辨率素材的左上角。

不能只因代码里存在 `384×128` 就断定高分辨率贴图被裁切。若该调用使用相同的源区域与纹理归一化分母，UV 仍可能覆盖完整图片。应检查实际采样方式，再决定是否修改资源尺寸处理。

### 首轮建议值

枪图相对当前显示尺寸等比缩小约 `5%–8%`，右锚点保持不变。这样左边缘自然向右收，增加与左侧竖条的间隔；不再额外平移整个枪图向右，避免越过右锚点。

保持图片区域的垂直中心稳定，兼顾不同枪包的透明留白。缩图只用于改善枪图内部留白，不把它误当成弹药区自动扩大。

## 3. 弹药：先提高对比度，再微调大小

### 优先改善清晰度

- 正常弹药文字不透明度由当前约 80% 提高至约 95%，作为初始调试值。
- 试加轻微暗色阴影，增强复杂地面、墙面及亮背景上的辨识度；避免粗重描边挤压字形。
- 低弹量仍使用项目现有红色提示，同时保持足够对比度。

截图中的细弱观感可能同时受到字体笔画、非整数缩放和截图缩放影响，尚不能认定单一原因。当前 `lineHeight - 2` 是可见字高估计，需用实际字体数字边界校准，不能把字体行高直接视为字形高度。

### 数字比例优先

```text
currentScale / reserveScale ≈ 8 / 3
```

若提高对比度后仍偏小，可尝试弹匣与备弹一起放大约 8%。这是可选的小幅调试，不是必须增大的硬指标。先检查右侧现有空间；如果不能容纳，则保持字号或微调内部留白，不通过扩大整个卡片解决。

常规三位弹匣、四位备弹保持稳定字号与共同右锚点。长数字按位数档位适配，两组数字使用共同缩放因子，不能只压小备弹或只放大弹匣。

像素对齐以稳定锚点和共同缩放为主，允许取整误差；不要分别取整两组字号后破坏大小比例。阴影不计入可见字高测量。

## 4. 射击模式与备弹：形成稳定的下行组合

模式图标适当向右靠拢，与备弹之间预留约一个备弹数字宽度的间隔。该间隔是视觉目标，按实际字形和图标透明留白校准，不机械套固定像素。

- 备弹继续右对齐，模式图标与备弹在同一行垂直居中。
- 按常规四位备弹区域确定图标位置，而非绑定每一帧字符串的实际左边缘。
- 弹药变化时图标不能横向跳动。
- 备弹超过四位时使用预留区域与联动缩放，不侵入模式图标及其间隔。
- 图标和枪图分别使用稳定锚点；移动模式图标不带动枪图。

## 5. 稀有度层与升级等级

建议把稀有度渐变移到枪图下方，减少彩色层对枪身的染色。项目配色不变，左侧仍为淡色，右侧更早淡出，降低弹药区域的色块感。

推荐绘制顺序：

```text
稀有度渐变 → 枪图 → 弹匣 / 备弹 / 升级等级 → 模式图标 → 浅灰竖条
```

起始 alpha 可先保留当前约 16%。渐变结束位置以减少弹药区干扰为目标，例如先试卡片宽度的 75%–85% 处降为透明，再根据实机亮暗背景调整；不新增厚重底板或外框。

升级等级继续位于左下角，高度略小于备弹。枪图缩小时保留等级的独立锚点，不跟随枪械轮廓变化。零级仍不显示；截图中没有等级，并不能单凭这一点认定渲染有误。

## 6. 实施优先级

1. 确认完整图片的右锚点与纹理采样方式，核对不同分辨率、相同比例素材。
2. 枪图小幅缩小，增加左侧留白；渐变移至枪图下方。
3. 提高弹药对比度，校准字形与像素落点。
4. 整理模式图标与备弹的间距和垂直对齐。
5. 仅在仍有必要且空间允许时，尝试数字组共同放大约 8%。

主要涉及 [ZombiesWeaponPanelLayout.java](../src/main/java/com/cdp/codpattern/client/gui/overlay/zombies/ZombiesWeaponPanelLayout.java) 的锚点与尺寸计算，以及 [ZombiesHudOverlay.java](../src/main/java/com/cdp/codpattern/client/gui/overlay/zombies/ZombiesHudOverlay.java) 的贴图、文字和图层顺序。

## 7. 验收标准

| 场景 | 验收要求 |
| --- | --- |
| 相同枪图，分别为 `384×128`、`768×256`、`1536×512` | 显示框尺寸与右边缘一致，无局部裁切或拉伸 |
| 相同比例、透明留白不同的枪图 | 对齐完整图片框，保留各自留白，不按轮廓自动裁切 |
| 枪图缩小前后 | 右边缘保持不动，左侧间隔增加，弹药锚点不动 |
| `030/0120`、低弹量及空弹匣 | 字体不更换，数字主次清楚，暗影不过重，低弹量提示有效 |
| 弹药数值变化或跨位数 | 共同右对齐、字号按档稳定、约 8:3 比例，模式图标不跳动 |
| 升级 0、I、II、III 及较长等级 | 零级隐藏，等级与枪图、弹药之间不重叠 |
| 明亮、暗处和复杂背景 | 枪身不被渐变染色，弹药可读，渐变不过度形成实色矩形 |
| 完整游戏画面、多 GUI 缩放 | 卡片保持紧凑，不因本轮调整明显增大，不挤压其他 HUD |

以上百分比为建议起点，最终以实机画面校准；不把原稿像素值或百分比写成不可调整的硬限制。

## 8. 本轮实施记录

- 外框维持 `246 × (156 × 240 / 586)` 参考单位；屏幕占比上限和右下角锚点不变。
- 枪图等比缩小 **6%**，完整图片框右边缘、垂直中心不变，保留透明留白；无 HUD 贴图时的物品图标也沿用右锚点。
- 贴图统一使用单位矩形和完整 UV `(0,0)–(1,1)`，由目标框决定显示尺寸；同为 `3:1` 的不同分辨率素材不影响显示大小。不新增每帧尺寸查询，也不自动裁剪透明边缘。不同宽高比素材不属于本轮支持范围。
- 原绘制调用的源区域与归一化分母相同，本来就覆盖完整纹理。本次是明确分辨率无关的采样规则，并非认定或修复了已证实的高分辨率裁切故障。
- 弹药不透明度改为 `242 / 255`（约 **95%**），加半个参考单位偏移的淡黑阴影。保留现有字体、常规字号和 **8:3** 比例；暂不采用可选的额外 8% 放大。
- 模式图标移近备弹，按固定四位备弹区域定位，间隔约一个常规备弹数字宽度。长数字仍通过共同缩放适配，图标不随数值移动。
- 稀有度渐变先绘制，枪图后绘制；起始 alpha 保持 `41 / 255`，在卡片宽度 **80%** 处淡为透明。配色继续读取项目映射，史诗紫为 `#A855F7`。
- 升级等级仍用独立左下角锚点，零级隐藏，保持略小于备弹；未修改游戏数据、SVG 原稿及其备份，也未改动独立前端演示。
